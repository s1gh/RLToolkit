Set up your identity

We need to know which player in the match is you so plugins can stamp your stats correctly. To claim yourself:

  1. Start Rocket League.
  2. Queue a private match by yourself (any playlist, any bots).
  3. Click your name in the roster below when it appears.

Don't see your name? Set up the Stats API
  1. Close Rocket League if it's running.
  2. Open <RL install dir>\TAGame\Config\DefaultStatsAPI.ini in a text editor.
  3. Set PacketSendRate=10. Any value greater than zero enables the websocket; 10 is plenty for an overlay.
  4. Confirm Port=49123 matches the port in Settings → Rocket League Stats API address.
  5. Save the file, restart Rocket League, queue a private match.
